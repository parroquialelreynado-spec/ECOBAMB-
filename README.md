# ECOBAMB-
ECOBAMBÚ es un emprendimiento escolar de la I.E. El Reynado, en Colasay, que aprovecha el Bambú Guayaquil para crear artesanías decorativas y funcionales. Elaboramos maceteros, organizadores, porta lapiceros, porta botellas y otros productos, promoviendo la creatividad, identidad local, sostenibilidad y emprendimiento.
